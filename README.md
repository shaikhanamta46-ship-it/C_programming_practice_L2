# C Programming Instructions and Operators.

This repository contains my practice programs while learning the fundamentals of C programming.

## Topics Covered

### 1. Variables and Data Types

* Integer (`int`)
* Float (`float`)
* Variable declaration
* Variable initialization
* Multiple variable declaration

### 2. Input and Output

* `printf()` function
* Format specifiers:

  * `%d` for integers
  * `%f` for floating-point numbers
  * `%c` for characters

### 3. Arithmetic Operators

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)
* Modulus (`%`)

### 4. Type Conversion

* Implicit Type Conversion
* Explicit Type Casting

### 5. Operator Precedence

* Understanding how expressions are evaluated
* Practical examples of arithmetic expressions

## Programs Included

### Program 1: Variable Declaration and Initialization

Demonstrates:

* Declaring variables
* Assigning values
* Printing multiple variables using `printf()`

### Program 2: Arithmetic Operations

Demonstrates:

* Addition of two numbers
* Modulus operator
* Basic arithmetic calculations

### Program 3: Float Division and Type Demotion

Demonstrates:

* Division involving float values
* Storing float values in integer variables (demotion)

### Program 4: Operator Precedence

Demonstrates:

* Evaluation of arithmetic expressions
* Understanding precedence and associativity

### Program 5: Type Casting

Demonstrates:

* Converting float values into integers using explicit type casting
